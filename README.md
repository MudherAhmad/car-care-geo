# Car Care Geo

AI-assisted vehicle pickup, address validation and driver routing with Geoapify.

## Purpose

Public reference implementation extracted from a real vehicle-service booking problem.
The production Car Care platform remains private.

## Features

- Structured Swedish address input
- Canonical address generation
- Geoapify geocoding
- Pickup and return validation
- Same pickup/return address handling
- Geoapify routing
- Automated tests
- OpenAPI and MCP experiments

## Security

Never commit API keys, production credentials, customer data or private production code.
